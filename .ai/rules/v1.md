# V1

## Normalize compact dates before Eloquent
Never assign a numeric `YYYYMMDD` string directly to an Eloquent `date` cast: numeric strings are interpreted as Unix timestamps and can become dates in 1970. Normalize valid compact dates to `YYYY-MM-DD` before model assignment and validate date-only inputs with `date_format:Y-m-d`.
