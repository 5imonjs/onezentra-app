# V1

## Normalize compact dates before Eloquent
Never assign a numeric `YYYYMMDD` string directly to an Eloquent `date` cast: numeric strings are interpreted as Unix timestamps and can become dates in 1970. Normalize valid compact dates to `YYYY-MM-DD` before model assignment and validate date-only inputs with `date_format:Y-m-d`.

## Log route as path, not generated name
Routes without an explicit `->name()` get `generated::...` names that change on every `route:cache`, and those names classify as "Lainnya" in the activity module CASE. `TrackUserActivity` therefore stores `$request->path()` when the route name starts with `generated::` — keep that fallback when touching activity logging, otherwise the Riwayat Aktivitas module filter breaks.
